# Group-2-Dormitory-Management-System-Project
Dormitory Management System 

Group 2 

 

 

 

 

 

A Java-based Dormitory Management System designed to manage 

resident repair requests, hall manager assignments, and 

maintenance tasks.

System Features 

- Resident repair request submission 

- Repair request tracking 

- Hall Manager request management 

- Maintenance staff assignment 

- Maintenance task updates 

- Repair status monitoring 

- Database record management 

 

Technologies Used 

- Java 

- MySQL 

- NetBeans 

- JDBC 

 

System Workflow 

Resident 

→ Submit Repair Request 

→ Database 

→ Hall Manager 

→ Assign Maintenance Staff 

→ Maintenance Staff 

→ Update Repair Status 

→ Completed 

 

 

Project Structure 

- `Programs/` – Java source code 

- `Database/` – SQL database and sample data 

- `UML/` – UML diagrams and system architecture 

- `Screenshots/` – system screenshots 

- `Documentation/` – user manual 

 

 How to Run 

1. Download or clone this repository. 

2. Import the Java project into NetBeans. 

3. Create the MySQL database. 

4. Run the SQL file in the `Database` folder. 

5. Update the database connection settings if necessary. 

6. Run the Java application.
